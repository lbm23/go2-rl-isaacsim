# Go2 当前策略抗推扰实验

日期：2026-10-22（Asia/Shanghai）；服务器：`<SSH_HOST>`。

本次只评测当前 `model_1998.pt`，未追加训练。结论：轻中等推力下可以恢复，但存在明显方向差异；向后和向右的强推扰是当前策略的短板。本次结果限定于下述施力位置、持续时间、速度和步态时刻，不能推广为任意推扰下的安全保证。

## 协议与时间上限

- 物理后端为 Isaac Lab v3.0.0 的 Newton/MJWarp，策略为之前训练的 RSL-RL PPO。
- 指令：机体前向 0.5 m/s、侧向/偏航指令为 0；平地、无额外随机推扰、无观测噪声。保留材质、机身质量和质心随机化。
- 从默认关节姿态和静止状态开始，重置的朝向偏移固定为 0；实际朝向在推力开始时重新测量。不同条件是独立随机样本，不是严格配对试验。
- 在第 5.0 秒开始，向机身 `base` 刚体质心施加 0.2 秒真实水平外力，未直接修改速度。无附加外力矩。方向按施力开始时的机体朝向定义，随后在世界坐标中保持不变。
- “向前”表示沿机体前向推，“向后”表示沿机体后向推；不是指力来自哪个方向。左/右同理。
- 强度为 0.25、0.5、1、2 BW。`F = 强度 × 当前机器人总质量 × 9.81`，BW 是体重对应的力；每次实际牛顿值和指令冲量均保存。
- 四方向 × 四强度 × 两种子（42、43）× 每种子 32 次 = **1024 次推扰试验**，另有 **64 次无推扰对照**，共 **1088 次矩阵试验**。每次仿真 15 秒，推力结束后观察 9.8 秒。
- 主流水线包含单元测试、两批评测、两次录像及结果生成，硬上限 **600 秒**（595 秒终止、5 秒后强制结束），实际 **85 秒**，正常退出。图表标注校正在原始实验截止时间内完成，未重新仿真或训练。
- 只使用第二张 RTX 5090 执行策略与物理计算。没有安装依赖、更换驱动或修改已有环境。

## 指标定义

- **跌倒**：原任务终止（机身接触地面），或者机身倾斜超过 60°/高度低于 0.18 m 的状态持续 0.2 秒。第一次跌倒后，自动重置不能抹掉失败。
- **恢复时间**：从推力撤去到首次连续 0.5 秒满足以下条件的稳定窗口起点：平面速度误差不大于 0.15 m/s、偏航角速度绝对值不大于 0.30 rad/s、机身倾角不大于 15°、机身高度不低于 0.28 m；且之后到试验结束都未跌倒。时间分辨率为 20 ms，窗口确认比报告的起点晚 0.5 秒。
- 跌倒或在观察期内未恢复的试验，恢复时间记为空值，不能记为 0 秒。恢复比例使用全部有效试验作分母；恢复时间的中位数/P90 只针对成功恢复的试验。
- **速度误差**：机体坐标系中，实际平面速度与 `(0.5, 0)` 指令之差的向量模长。表中的推后均值从撤去推力后统计到第一次跌倒前；不计自动重置后的数据。不同失败条件观察时长不同，必须和跌倒率一起看。
- 所有矩阵试验在推力开始前都未跌倒，有效样本均为每格 64 次。另保存推前误差、峰值误差、质量、世界坐标推力、冲量、跌倒时刻和恢复状态。
